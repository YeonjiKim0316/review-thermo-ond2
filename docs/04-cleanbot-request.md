## 1. 왜 필요한가요?

- 리뷰에 전화번호나 이메일을 적는 고객이 있습니다. 그대로 올라가면 개인정보가 드러납니다.
- 욕설이 들어간 리뷰는 다른 고객이 불쾌해합니다.
- "좋아요" 한 마디 같은 리뷰는 다른 고객에게 도움이 안 됩니다.

## 2. 요청

1. 리뷰를 올리기 전에 **전화번호와 이메일을 가려** 주세요.
2. **욕설**이 있으면 올리지 말고, 고객에게 고쳐 달라고 알려 주세요.
3. **너무 짧은 리뷰**는 올리지 말고, 조금 더 써 달라고 알려 주세요.
4. 문제가 없으면 그대로 올려 주세요.

## 3. 지켜 주세요

- 리뷰를 저장하지 않습니다.
- 리뷰를 회사 밖 AI 서비스로 보내지 않습니다.
- 새 패키지는 pytest 말고는 설치하지 않습니다.
- 테스트를 통과한 코드만 받습니다.

## 4. 아직 정하지 않은 것

CS팀도 아직 정하지 못했습니다. 개발팀이 물어봐 주세요.
