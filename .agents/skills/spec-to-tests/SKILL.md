# 예시표 → 테스트 행

수업 저장소(하루마켓 리뷰 온도계)에서 명세의 예시표를 테스트로 옮길 때 쓰는 스킬입니다.

## 순서

1. SPEC.md에서 적어 준 함수들의 예시표를 찾는다. 함수 이름을 적지 않았으면 SPEC.md의 모든 예시표를 옮긴다.
2. 표 한 줄을 `pytest.param` 한 줄로 옮긴다. id는 입력값으로 짓는다. 모양은 `examples/row.py` 를 따른다.
3. 표에 없는 행은 만들지 않는다. 숫자와 문자열은 표 그대로 쓴다.
4. 사용자가 이미 쓴 테스트가 있으면 지우거나 바꾸지 않는다. 같은 파일에 이어서 추가한다. 사용자가 쓴 테스트와 같은 행은 다시 만들지 않는다.
5. `tests/test_thermo.py` 만 고친다. `app/` 와 `SPEC.md` 는 고치지 않는다.
6. `pytest -v` 를 실행하고, 표의 행 수와 테스트 행 수, passed/failed 개수를 보고한다.

## 하지 말 것

- 사용자가 쓴 테스트를 지우거나 기대값을 바꾸지 않는다.
- 테스트가 실패한다고 기대값을 바꾸지 않는다. 지금 단계에서는 실패(Red)가 정상이다.
- 새 패키지를 설치하지 않는다.
